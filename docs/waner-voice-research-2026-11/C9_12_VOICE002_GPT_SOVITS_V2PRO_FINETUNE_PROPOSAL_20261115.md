# C9-12 Voice 002：GPT-SoVITS v2Pro专属微调方案（仅规划）

## 1. 已有事实与结论边界

- Voice 002原始WAV共13段、合计150.84秒、48 kHz/16-bit/单声道，全部可读且零削顶；每条共同触发低电平**采样点比例**提示，该指标不是连续静音时长。
- 本地试听：A03自然主参考最佳、A02备用、B02开心表现正常、E01温柔表达正常。
- IndexTTS 2.5 BASE CPU/FP32使用A03完成2条零样本WAV，试听反馈：L1_01像本人3/5、自然度4/5、语气平淡；L1_02像本人4/5、自然度4/5，重音“再”不足。
- 新A02单参考对照上传报告 `C9_11_A02_CONTROL_SAFE_RESULT_run_20261115T081645_958021_def64a5e.json`，结果`A02_CONTROL_1_WAV_READY_HUMAN_REVIEW_REQUIRED`，1条2.67秒WAV、70.55秒耗时、CPU/FP32、无训练、工作器报告未修改生产文件。**尚无A02对应的主观试听评价**；须保留对照记录，不能声称优于A03。
- 新GPT-SoVITS通用模型静态清点 `C9_11_GPT_GENERIC_INVENTORY_20261115T082106_64746aa1.json`，存在v2Pro相关预训练候选`v2Pro/s2Gv2Pro.pth`、`v2Pro/s2Dv2Pro.pth`及ProPlus对应项、GPT通用预训练候选、说话人编码模型；`license_version_and_upstream_sha_not_verified=true`，`runtime_compatibility_not_tested=true`，**不能等同于训练环境/权重身份已经最终验收**。
- 用户倾向优先通过**单独微调GPT-SoVITS v2Pro，为Voice 002建立专属模型**，而非再重复其零样本推理。官方GPT-SoVITS支持约1分钟语音的few-shot微调，但效果依赖数据、版本、训练参数，不保证此素材即可达到生产要求。

## 2. 最小受控训练计划：先审数据，后申请一次训练

### A. 数据准入与训练集构建（不训练）

1. 保留13条原始WAV只读；从A01–A03及F01–F04自然日常录音优先制作约97.56秒的**核心候选数据**。B01/B02/E01/E02作为可选多样表达素材，C01/D01的强情绪暂不自动混入首轮基线。
2. 在独立VoiceFactory工作区生成切片副本；F组长句按语义/停顿切分为适合本地v2Pro版本的数据单位，保留每段准确转写、统一人物、source→segment的SHA和编号，不能假定官方固定时长为硬门槛。
3. 实际听验和文本对齐：消除前后空白、文字/声音不符、误切、多人声、明显噪声/混响；保留高质量自然语气，原始录音不做破坏性处理。异常样本隔离而非偷偷裁切替换。
4. 保留一组没参与训练的测试句，基于现有A03与A02参考进行训练前后比较。避免使用训练音频本身就能被直接记住的原句来断言泛化成功。
5. 数据来源、说话者对**本地专属模型训练**的知情同意须与之前“本地检查/零样本克隆”的许可分开核实。

### B. 冻结训练配方、资源与回滚（只读/规划）

1. 以本机已安装的GPT-SoVITS v2Pro-20250604为目标**冻结版本**，核对与本机通用预训练权重的兼容及许可和上游摘要。不得使用婉儿专属SoVITS/GPT权重作为Voice 002的起始模型。
2. 基于既有RTX3070 8 GiB与32 GiB RAM制定保守参数（小batch、混合精度兼容性检查、分阶段SoVITS/GPT微调）；先做可在独立实验区执行的资源预检，再决定具体epoch/steps。**不能对当前用户环境擅自承诺一定能同时保持生产GPU推理可用**。
3. 生产服务（9880/9890、OpenClaw、Gateway、旧Studio）默认不变。首次GPU训练前单独明确排期、显存隔离/检查、独立进程、训练检查点输出与失败回滚，不能无审批停止或热切换生产服务。
4. 输出只写新`VoiceFactory/experiments/voice_002_gsv_v2pro_finetune`目录：配置、输入清单SHA、训练日志、SoVITS/GPT模型权重、受控试声和回滚清单；无密钥、原WAV或权重上传Public仓库。

### C. 训练之后的实机验收

- 在独立推理环境用**相同未见文本**比较新模型对未微调通用底模、IndexTTS BASE A03/A02结果的听感（像本人、自然度、重音、语速、断句）；
- 记录训练GPU占用、墙钟耗时、推理延迟、显存及稳定性；只在主观质量和操作稳定性满足要求后研究是否导入Voice Studio运行时Registry；
