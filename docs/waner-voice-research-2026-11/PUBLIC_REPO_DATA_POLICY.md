# Public仓库声音资产与信息安全政策

**2026-11-11：已核实仓库公开，当前有 `audio source/` 5个WAV和 `audio source-v2/` 6个WAV，共11个公开参考音频。**

本次归档**没有上传、修改或删除**这些历史录音。目前没有证据证明每个录音已取得长期公开传播、克隆及后续商业使用授权；应由仓库所有者审查。

## 从现在起禁止向Public仓库新增

- 真实人物原声、切片、完整训练语料/转写、模型权重/checkpoint、完整评分与私有解盲原件；
- 访问Token、密码、SSH私钥、敏感运行日志、未公开内部服务配置；
- 未明确取得公开许可的声音、衍生音频或模型。

Public仅放脱敏研究摘要、架构说明、获准公开的通用代码与不泄露数据原件的证据索引；敏感资产在受控私有存储，用受控ID和SHA关联。提交前须检查敏感字符串、音频/模型大文件、权限与许可；通过PR评审。

## 对现有11个WAV的建议

1. 逐个核对权利人、允许的用途、公开范围和保留期限。
2. 未确认前**不要复制到新的公共项目**或公开发布新增训练模型。
3. 若公开许可不充分，再决定将仓库改Private、移除或清理Git历史；采取破坏性操作前必须评估备份及与生产参考音频之间的关联。
4. 改Private或删除当前分支文件，**不能撤销既有第三方下载或Fork**，也不能保证历史彻底消失。

本次操作仅新增文档分支，未对生产系统或历史声音资产执行任何改变。
