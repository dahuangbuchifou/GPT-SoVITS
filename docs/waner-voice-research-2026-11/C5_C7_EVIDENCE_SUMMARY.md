# C5–C7 研究证据总结（2026-11-11）

**范围：婉儿 GPT-SoVITS、IndexTTS 2.5 BASE、LoRA150。性质：探索性单人盲听，非生产替换验收。**

## 已核对的阶段结果

|阶段|比较|已解盲结论|
|---|---|---|
|C5|BASE / LoRA150；FAM02、DAY01，各两种子|BASE 2/4，LoRA150 2/4；BASE胜FAM02，LoRA胜DAY01|
|C6|GPT-SoVITS / LoRA150 / BASE；两文本各两次|GPT第一2/4，LoRA第一2/4，BASE第一0/4；GPT和LoRA五项等权均分均4.30|
|C7|GPT-SoVITS / LoRA150；6条新设计文本|GPT-SoVITS 4/6，LoRA150 2/6|

C7各模型平均评分（1–5分）：

|维度|GPT-SoVITS|LoRA150|
|---|---:|---:|
|自然度|4.67|4.00|
|流畅度|4.33|4.17|
|像婉儿|4.17|4.17|
|情绪适配|4.00|3.67|
|东北口音自然度|4.33|3.83|
|整体听感|4.17|3.83|
|六项等权辅助均分|4.28|3.94|

C6+C7的直接偏好计数为GPT **6/10**、LoRA **4/10**；这些观察并非10次独立测试（C6重复文本、复用C5音频），不能据此推断统计显著性。

## 技术事实与界限

- C5在经限定授权的234条训练样本上进行了150次优化器调用，真实adapter与合并GPT严格加载检查通过；另48条诊断、47条封存未参与优化，#017排除。**预算已耗尽，不得未经新授权继续训练。**
- C5 CPU/FP32运行完整生成8条原始WAV，C6复用其中8条并额外生成4条GPT-SoVITS音频，C7对6条新文本生成12条音频。
- C5中FAM02偏好BASE，C6同一批原始BASE/LoRA音频却偏好LoRA，属于必须保留的主观评价反例；不能推断改善稳健。
- C7仍是单评者小样本；“新文本”不代表已验证训练来源独立。既往数据存在多编号切自同源长录音的可能性。
- C6/C7仅有生产启动配置检查，不能独立排除运行中权重热切换；没有完成本地所有WAV的二次逐字节核验，也不能声称EOS、漏字/重复等全面客观通过。
- IndexTTS CPU推理可行，但没有足够的统一时延/资源统计支持实时服务SLA声明。

## 当前决定

**GPT-SoVITS保持正式生产；LoRA150为候选；BASE为研究基线。** 不修改生产服务，不自动训练或生成，新增验证须针对具体问题并取得授权。
