# 婉儿声音研究：C5–C7 归档与 C8/C9 交接

**归档日期：2026-11-11。文档性质：研究证据与设计规划，不是生产部署说明。**

本目录保存 IndexTTS 2.5 LoRA150 与 GPT-SoVITS 的探索性试听总结，以及从婉儿样板发展为多声音 Voice Factory 的阶段计划。

## 当前明确结论

- GPT-SoVITS **继续作为婉儿默认生产语音引擎**；现有稳定权重、Gateway、OpenClaw/API 与 Studio 基线不变。
- IndexTTS LoRA150 在部分表达场景有优势，但未证明全面胜过 GPT-SoVITS；保留为研究候选。BASE 保留为研究对照。
- C5–C7 为有限文本、主要单评者的探索性盲听，不构成统计显著结论、来源独立泛化证明或生产切换验收。
- 无新的训练、自动音频生成、生产切换授权。
